## 🚀 Selected Projects

**[Flokte](https://apps.shopify.com/flokte-return-insights)** — live Shopify app · *Go, PostgreSQL, Redis, Docker, Next.js*
Return-behaviour risk scoring for Shopify merchants. It scores customers on factors like return rate, routes flagged patterns to a human review queue with evidence for chargeback disputes, and shares scores across stores without exposing any store's order data. [View it on the Shopify App Store →](https://apps.shopify.com/flokte-return-insights)

**Every Car Can (ECC)** — US vehicle-auction platform · *Laravel, Node.js, Next.js, PostgreSQL, MongoDB*
A full replacement platform with live bidding and real-time chat for **500+ concurrent users**, automated payments and documents, and role-based modules across six departments. Delivered in **7 months** against a 2-year estimate.

**SYSPRO ERP Payment Integrations** · *C#, .NET*
Custom integrations embedding Moneris, Payroc and Factor4 into a SYSPRO ERP, covering card-present, card-not-present and gift-card transactions.

**Multi-Site Data Collection Pipeline** · *Go, Python, Playwright, AWS EC2*
Collected data from 15 websites on a 5-minute refresh cycle by replaying each site's own HTTP requests instead of running full browser automation. Each customer is isolated on its own instance, which avoided an estimated **$18,000/year** in proxy costs. [Read the write-up on Medium →](https://medium.com/@hassanalgo12/the-imposible-scrape-3482a13f7177)
